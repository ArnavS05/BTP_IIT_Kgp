# TinyC AVX Compiler

This project compiles a restricted TinyC program into scalar three-address code, passes it through the SIMD optimizer, performs register allocation and simulates the final TAC.

## Build

The project requires GCC/G++, Flex, Bison, Make and Bash.

```bash
make
```

## Run the complete pipeline

Run using the default configuration:

```bash
./scripts/run_pipeline.sh input.tc
```

The defaults are 8-byte alignment, 16 scalar registers, 16 vector registers and a 256-bit vector width. They are written near the top of `scripts/run_pipeline.sh` and can be edited directly.

Values can also be overridden for one run:

```bash
./scripts/run_pipeline.sh input.tc \
    --alignment 4 \
    --scalar-registers 8 \
    --vector-registers 8 \
    --vector-width 512
```

The Makefile provides a shorter default-only command:

```bash
make run INPUT=input.tc
```

## Input and output

The input must be a valid TinyC source file. The output directory is named `output_<input-file-name>` after removing the file extension. For example, `input.tc` uses `output_input/`.

| File | Generated by | Description |
| --- | --- | --- |
| `info.txt` | Basic Compiler | Contains the type table, symbol tables, variable offsets, sizes and alignment information |
| `scalar_tac.txt` | Basic Compiler | Contains the typed scalar three-address |
| `simd_tac.txt` | SIMD optimizer | Contains TAC after SIMD vectorization |
| `allocated_tac.txt` | Register allocator | Contains TAC using physical scalar and vector registers, including any inserted spill instructions |
| `simulation_report.txt` | Processor simulator | Contains instruction and cycle counts, memory operations, spills, estimated SIMD speedup and source-line statistics. |
