# TinyC AVX Compiler

This project compiles a restricted TinyC program into scalar three-address code, passes it through the SIMD optimizer, performs register allocation and simulates the final TAC.

## Build

The project requires GCC/G++, Flex, Bison, Make and Bash.

```bash
make
```

## Run the complete pipeline

Run using the default configuration:

```bash
./scripts/run_pipeline.sh input.tc
```

The defaults are 8-byte alignment, 16 scalar registers, 16 vector registers and a 256-bit vector width. They are written near the top of `scripts/run_pipeline.sh` and can be edited directly.

Values can also be overridden for one run:

```bash
./scripts/run_pipeline.sh input.tc \
    --alignment 4 \
    --scalar-registers 8 \
    --vector-registers 8 \
    --vector-width 512
```

The Makefile provides a shorter default-only command:

```bash
make run INPUT=input.tc
```

## Input and output

The input must be a valid TinyC source file. All output files are written beside the source file. For example, `./Examples/Eg1/Eg1.tc` produces its outputs directly inside `./Examples/Eg1/`. The following table lists the normal-mode outputs.

| File | Generated by | Description |
| --- | --- | --- |
| `info.txt` | Basic Compiler | Contains the type table, symbol tables, variable offsets, sizes and alignment information |
| `scalar_tac.txt` | Basic Compiler | Contains the typed scalar three-address |
| `simd_tac.txt` | SIMD optimizer | Contains TAC after SIMD vectorization |
| `allocated_tac.txt` | Register allocator | Contains TAC using physical scalar and vector registers, including any inserted spill instructions |
| `simulation_report.txt` | Processor simulator | Contains instruction and cycle counts, memory operations, spills, estimated SIMD speedup and source-line statistics. |




## Compare scalar and SIMD execution

Use `--test` to run both versions with the same configuration:

```bash
./scripts/run_pipeline.sh "./Examples/Eg1/Eg1.tc" --test
```

Custom configuration options can be combined with `--test`.

The compiler and SIMD optimizer run once. Register allocation and simulation run separately for scalar and SIMD TAC, producing:

| File | Description |
| --- | --- |
| `allocated_scalar_tac.txt` | Allocated TAC without SIMD optimization |
| `allocated_simd_tac.txt` | Allocated TAC with SIMD optimization |
| `scalar_simulation_report.txt` | Scalar execution statistics |
| `simd_simulation_report.txt` | SIMD execution statistics |
| `comparison.txt` | Both cycle totals, measured speedup and percentage cycle reduction |

`info.txt`, `scalar_tac.txt` and `simd_tac.txt` are also generated. Measured speedup is scalar cycles divided by SIMD cycles; it differs from the simulator report’s approximate estimated speedup.
